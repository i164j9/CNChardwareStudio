CNC Hardware Studio

Quick-start tutorial

Open the calculator

What this app does

The Studio runs engineering formulas in blocks. A block takes numeric inputs and displays a result. You can connect a later block to an earlier result with a pipe, making a simple calculation pipeline. The math library uses metric units unless a formula name or input below says otherwise.

Offline use

Styling is bundled in the local cncHardwareStyles.css file; the pages no longer fetch Tailwind from a CDN. Keep that CSS file and cncHardwareMath.js beside the HTML files. For browsers that restrict JavaScript modules opened with a file:// URL, launch the folder using a local web server such as VS Code Live Server. Once the files and local server are available, the app does not need internet access.

Developers can rebuild the stylesheet after changing utility classes with npm install and npm run build:css. The generated CSS is already included for normal use.

Create and configure a block

  1. Open the calculator and choose Add Formula Block.
  2. Select a formula from the dropdown at the top of the block.
  3. Enter a number for each input. The result recalculates as you edit values.
  4. Hover over an input name or its ⓘ help marker to see a plain-language description and unit guidance.
  5. Use the Value / Pipe selector to enter a value directly or reuse an earlier block’s output.
  6. Change the output variable name if you want a more descriptive label in the ledger.

Inputs start at zero. Many formulas require positive values, so a block can show an error until you enter valid inputs. Hover over “Error” to see the formula’s error message.

Example: calculate steps per millimeter

For a 200-step motor, 16× microstepping, a 2 mm belt pitch, and a 20-tooth pulley, select stepperPureBeltStepsPerMm and enter:

InputValue
motorSteps200
microstepping16
beltPitch2
pulleyTeeth20

The result is 80 steps/mm. This is a calibration estimate from the entered mechanical dimensions; verify it against the actual machine.

Connect blocks with a pipe

Add another block after the first. Its Pipe dropdown can select outputs from earlier blocks. For example, pipe an earlier DC current result into the current input of dcPowerWatts, then enter a voltage in the other input. The ledger lists the current outputs and their values.

Blocks run from top to bottom. Only outputs from blocks above the current block are available, so arrange a producer before the block that uses its result.

Graph a parameter sweep

  1. Turn on 📊 Graph Sweep in a formula block.
  2. Choose which numeric input to sweep. The graph recalculates the formula at each sample.
  3. Set the minimum and maximum for that input, then choose a sample count from 2 to 500.
  4. All other inputs stay at their current literal values or piped results.

The horizontal axis is the selected input and the vertical axis is the formula result. Invalid samples (for example, values outside a formula’s valid domain) are omitted and reported beneath the graph. The graph updates as pipeline inputs change and is saved with the block when you export JSON.

The thrust-to-torque formula defaults to sweeping 0–2,500 N in 100 N increments. The reflected-load inertia formula defaults to sweeping gantry mass from 5–150 kg in 5 kg increments. Both presets can be adjusted. The torque graph shows required motor torque, not the motor’s holding-torque rating.

Other common sweep inputs also start with convenient ranges: frequency (10–1,000 Hz), inductance (0.5–10 mH or 0.001–0.1 H, depending on the formula’s units), steps or counts per millimeter (10–2,000), and rotational speed (0–3,000 rpm). These are starting points, not hardware limits; change the range to match the system being analyzed.

When graphing reflected linear-load inertia, the Studio also plots inertial torque against reflected inertia and overlays reflected inertia and inertial torque against gantry mass on separate vertical scales. The same block also estimates torque-producing motor current and DC bus current through a simplified acceleration/deceleration cycle. Enter the motor torque constant (N·m/A), DC bus voltage, motor/drive efficiency, and acceleration and deceleration durations. Choose either linear axis acceleration (m/s²), converted using screw lead and gear ratio, or motor angular acceleration (rad/s²), converted back to linear acceleration for the annotation.

Inertial torque is reflected inertia × motor angular acceleration, and torque-producing current is torque divided by the torque constant. Estimated DC bus current is derived from mechanical power (torque × angular velocity), bus voltage, and efficiency; it can be negative during deceleration to represent idealized regeneration. This estimate excludes winding copper losses, cutting force, friction, drive-specific current control, motor thermal limits, and real regenerative-bus behavior. Enabled block graphs are also collected at the end of the pipeline in the Pipeline Graphs section.

A sweep is a mathematical exploration, not a safety certification. Ensure the chosen parameter range is physically appropriate before using results to select or operate hardware.

Formula reference

Motion and mechanics

Stepper/servo resolution, mechanical resolution, maximum feed rate, cylinder and reflected inertia, inertia ratio, torque for thrust, torque-to-watts, and calibration.

Electrical

DC and AC current, RMS/peak conversions, single- and balanced three-phase real/apparent/reactive power and power factor, estimated stepper supply current, series RLC impedance/current/phase, reactance, resonance, and stored energy.

Conversions

Length, mass, force, torque, power, steps/mm to steps/inch, and AWG-to-area conversions.

Units to check

For example: wire length in meters, inductance in henries, capacitance in farads, frequency in hertz, and screw lead in millimeters or meters as specified by the selected formula.

The visual block editor accepts numeric inputs. The stepper supply-current block presents its options as individual numeric fields: provide exactly one of phase voltage or winding resistance. Helpers requiring arbitrary arrays or specialized wire options, such as combining a list of PSU loads or choosing an AWG/material for wire-drop calculations, remain available in the JavaScript library but are not yet exposed as blocks.

AC formulas and when to use them

AC formulas below use RMS voltage and current unless the name says peak. RMS values are the effective values normally printed on AC equipment and meters. For a sine wave, peak = RMS × √2.

Current from real power

Single phase: I = P / (V × PF). Balanced three phase: I = P / (√3 × Vline × PF). Use watts, volts RMS, and a power factor from 0 to 1. For example, 1,000 W at 230 V and PF 0.8 is about 5.43 A single-phase.

Real, apparent, and reactive power

Single phase apparent power: S = V × I VA; real power: P = V × I × PF W. Balanced three phase uses S = √3 × Vline × Iline and P = √3 × Vline × Iline × PF. Reactive power magnitude is Q = S × √(1 − PF²) var. The reactive-power helpers return magnitude only, not whether the load is leading or lagging.

Power factor and series RLC

Power factor is P / S. Series RLC formulas use resistance in ohms, inductance in henries, capacitance in farads, and frequency in hertz: XL = 2πfL, XC = 1/(2πfC), and |Z| = √(R² + (XL − XC)²). The phase-angle helper returns radians: positive is inductive and negative is capacitive.

Three-phase helpers assume a balanced system and use line-to-line RMS voltage with line RMS current. AC current and power calculations based on real power assume sinusoidal quantities and a meaningful power factor; nonlinear loads with harmonic distortion may need true-RMS measurements and more detailed analysis. Ideal RLC results do not include component tolerances, losses, saturation, or parasitic effects.

Estimate stepper DC supply current

Select estimateStepperSupplyCurrent to estimate supply-side current from DC supply voltage and motor phase current. Enter exactly one of phase voltage or winding resistance; the optional energized-phase count defaults to 2 and driver efficiency defaults to 0.9. The estimate uses phase electrical power and does not model a driver’s switching behavior, motion-dependent current, or actual motor/driver losses. Treat it as a rough estimate, not a substitute for the driver manufacturer’s supply-current specifications.

Save and load your pipeline

  • Save JSON downloads the current block setup and values.
  • Load JSON rebuilds blocks from a previously saved Studio file.
  • Loading replaces the blocks currently on the canvas.
  • Use the block’s delete button to remove it; downstream pipes that depended on it may need a new source.

Safety and engineering note

These calculations are estimates, not a substitute for manufacturer specifications, qualified engineering review, electrical codes, wire ampacity checks, or machine testing. In particular, stepper phase current is not the same as a driver’s DC supply current. Check component ratings and verify any design before building or operating equipment.
